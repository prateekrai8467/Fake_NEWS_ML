Fake News Detection Using Machine Learning

**AIL0303 — Machine Learning Principles | Research PBL**

An English-language news classification project using natural language processing (NLP), TF-IDF and supervised machine learning. The implementation compares four classifiers, evaluates the best cross-validation candidate on held-out data, and exports a Logistic Regression pipeline for inference.

1. Objectives

- Classify articles into the dataset's Fake and Real categories.
- Reduce dependence on obvious publisher markers through text cleaning.
- Compare classifiers using training-only stratified cross-validation.
- Examine classification errors, influential terms and decision thresholds.
- Export a reusable model and investigate chronological generalization.

2. System architecture

Architecture flow (Mermaid notation):
flowchart TD
    A[Fake.csv and True.csv] --> B[Label and concatenate title and text]
    B --> C[Remove short and exact duplicate articles]
    C --> D[Clean text]
    D --> E[Stratified 80/20 split]
    E --> F[80% training data]
    E --> G[20% held-out test data]
    F --> H[Five-fold CV: TF-IDF inside each pipeline]
    H --> I[LR / Linear SVM / Passive Aggressive / NB]
    I --> J[Select highest mean CV F1]
    J --> K[Fit selected pipeline on training data]
    G --> L[Held-out evaluation]
    K --> L
    L --> M[Report / confusion matrix / error analysis]
    K --> N[Save baseline pipeline]
    D --> O[Fit Logistic Regression on all cleaned data]
    O --> P[Save final pipeline]
    D --> Q[Optional chronological split]
    Q --> R[Temporal evaluation]
    S[New article] --> T[Same text cleaning]
    T --> P
    P --> U[Fake or Real prediction]


The baseline export and final export are distinct: the former is the CV-selected classifier trained on the training partition; the latter is always Logistic Regression fitted on all cleaned records. The final export has no independent holdout score of its own.

4. Dataset

Use the ISOT-style Fake.csv and True.csv files from the project dataset. Reference: [University of Victoria ISOT Fake News Dataset](https://www.uvic.ca/ecs/ece/isot/datasets/fake-news/index.php). Check dataset usage permissions before redistribution.

| Column | Purpose |
|---|---|
| title | Article headline |
| text | Article body |
| date | Publication date; required by the current script, used for temporal evaluation |
| subject | May exist in the source CSV; not used as a model feature |
| label | Generated by the script: 0 = Fake, 1 = Real |

The script concatenates both files, fills missing titles and bodies with empty strings, combines headline and body, removes content of 20 characters or fewer and drops exact duplicate combined texts. It does not explicitly resolve conflicting labels or remove near duplicates. Dates that cannot be parsed become missing values.

5. Preprocessing and feature extraction

`clean_text()` removes an initial Reuters dateline when matched by the regular expression, converts text to lowercase, removes URLs and HTML tags, replaces non-English-letter characters with spaces and normalizes whitespace. The TF-IDF vectorizer additionally excludes scikit-learn English stop words plus `reuters`, `said`, `image`, `featured`, `getty`, and `via`.

| TF-IDF setting | Value |
|---|---|
| Maximum vocabulary | 20,000 |
| N-grams | Unigrams and bigrams (1, 2) |
| Minimum document frequency | 3 |
| Maximum document frequency | 0.9 |
| Sublinear term frequency | Enabled |

TF-IDF weights terms by their frequency and rarity across documents. Keeping it inside each scikit-learn Pipeline ensures vocabulary and IDF are fitted only on the relevant training fold during cross-validation.

6. Machine learning algorithms

| Model | Configuration | Role |
|---|---|---|
| Logistic Regression | C=5, max_iter=1000 | Linear probabilistic classifier; final export |
| Linear SVM | LinearSVC, C=1.0 | Maximum-margin classifier |
| Passive Aggressive | max_iter=1000, random_state=42 | Online-style linear classifier |
| Multinomial Naive Bayes | Library defaults | Probabilistic text classification |

No Random Forest, hyperparameter grid search, paired source-masking experiment or calibrated SVM is implemented in this notebook. Although GridSearchCV is imported, it is not used.

9. Training and evaluation

- Stratified 80:20 train/test split with random seed 42.
- Five-fold stratified, shuffled CV on training data only; `n_jobs=-1` uses available workers.
- Compare mean CV accuracy, mean CV F1 and standard deviation of fold F1.
- Select the highest mean CV F1, fit on training data and evaluate on the held-out test set.
- Print per-class precision, recall, F1 and support; display a confusion matrix.
- Inspect 20 strongest terms in each direction when the classifier has coefficients, and print up to 15 misclassified titles and article-length summaries.
- Inspect decision thresholds from -0.5 to 0.5 when supported. This is exploratory test-set analysis, not a validated threshold-selection procedure.
- Fit final Logistic Regression on all cleaned data and save it.
- For chronological evaluation, sort valid dates, train on the earliest 80% and test on the latest 20% of those records.

**Metric interpretation:** CV uses binary F1 with positive label 1 (Real), not macro F1. Accuracy is the fraction of correct predictions. Precision measures correctness among predicted members of a class; recall measures coverage of actual members; F1 is their harmonic mean. Confusion matrix rows are actual labels and columns predicted labels. Positive linear coefficients favor Real; negative coefficients favor Fake. These associations are not causal explanations.

11. Predict a new article

The saved pipeline contains TF-IDF and the classifier, **not** the external cleaning function. Apply identical cleaning before inference. The following example can be saved separately as `predict.py` in the project directory. Do not import the training script merely to access its cleaner: its top-level code will rerun training.

python
import re
import joblib


def clean_text(text):
    text = str(text)
    text = re.sub(r'^.{0,120}?\(reuters\)\s*-?\s*', '', text, flags=re.I)
    text = text.lower()
    text = re.sub(r'https?://\S+|www\.\S+', ' ', text)
    text = re.sub(r'<.*?>', ' ', text)
    text = re.sub(r'[^a-z\s]', ' ', text)
    return re.sub(r'\s+', ' ', text).strip()


model = joblib.load('fake_news_pipeline.pkl')
article = input('Enter news headline and article: ')
cleaned = clean_text(article)
if not cleaned:
    raise ValueError('Please enter non-empty English text.')
label = model.predict([cleaned])[0]
confidence = model.predict_proba([cleaned])[0].max()
print('Prediction:', 'Real' if label == 1 else 'Fake')
print('Model probability:', round(float(confidence), 3))


Run `python predict.py` after training. Load only trusted pickle/joblib files; they can execute code during loading. Model probability is not verified factual confidence. The notebook's fallback sigmoid of the absolute decision score for non-probabilistic classifiers is also not calibrated.

12. Troubleshooting

| Problem | Suggested action |

| KeyError: title/text/date | Check required CSV headers. |
| ModuleNotFoundError | Install dependencies in the active Python environment. |
| High RAM usage or worker failure | Reduce CV `n_jobs` to 1 or 2; this is a local code change. |
| Plot blocks execution | Close the Matplotlib window. |
| Temporal split fails | Inspect valid dates and class coverage; skip the optional section if unsuitable. |
| Pickle version mismatch | Use the same package versions as training or retrain. |
| Unexpected predictions | Supply full English text and apply the same cleaner; verify claims independently. |

13. Research limitations and reproducibility

The notebook is a text classification experiment, not an evidence-based fact-checking system. Source, topic and writing-style shortcuts may remain despite cleaning. Exact deduplication does not guarantee independence after cleaning. Random splits may overestimate performance on unseen publishers or events. The chronological split is internal validation, not external validation; invalid dates and class imbalance may affect it. The final all-data model should be evaluated on a separate untouched dataset before reporting deployment performance. Random seed 42 controls the split and CV, but not every estimator's randomness; versions and hardware may also affect reproducibility.

Consistency with the earlier research manuscript

The earlier paper used an 8,000-record sample, 5,000 unigram features, Random Forest and calibrated SVM, a majority baseline, Fake=1, and paired original versus source-masked experiments. This notebook instead uses the full cleaned dataset, 20,000 unigram/bigram features, Passive Aggressive, Fake=0, and five-fold CV. Do not reuse the earlier paper's accuracy figures as results of this notebook. Align the manuscript and implementation or submit the original experimental code with the original results.
